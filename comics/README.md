# Comics

Finished issues of the printed comics, one folder per series. Each issue has two PDFs:

- `<nn>_<title>.pdf` – the A4 pages (greyscale, for a B&W laser printer)
- `<nn>_<title>_BROZURA.pdf` – the same pages as an A5 booklet: print duplex, flip on the short
  edge, fold each sheet, and nest them

Build them from `art/` as described in `docs/comic-workflow.md`.

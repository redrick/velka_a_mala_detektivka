# Game 1 – Záhada zmizelých ponožek (design draft)

This follows the comic, simplified into a playable loop. All text is in Czech. Every line gets a voice clip
(file name = line id). A parent can record them, or the girls can voice their own characters.

## Rooms
1. **zahrada** (garden): the clothesline, babička, the house door, Joey's bed, Tonda at the fence, the path to the kitchen garden.
2. **kuchyne** (kitchen): babička, the flour on a shelf, the window.
3. **zahrada_noc** (garden at night): a short cutscene. The dormouse silhouette takes the sock.
4. **zahumenek** (pumpkin patch, fence gap, raspberry bush, stream with stepping stones): the trail.
5. **kulna** (shed, inside): dark. It needs Hanka's torch. The old boot is on the shelf.
6. (Ending) The birdhouse is built. A star-key teaser leads to the next game.

## Puzzle chain
1. **Talk to babička** at the clothesline. The case starts and Alica's notebook is added to the inventory.
2. **Look with the magnifier** (Alica) under the line. Tiny footprints appear. Hanka, being small, notices them too.
3. **Joey's bed**: Hanka finds a sock ("Joey je zloděj!"). Alica inspects it: it's old and chewed, so Joey is innocent.
   *(False lead: must be resolved before continuing.)*
4. **Tonda at the fence**: "…mělo to huňatý ocásek!" This unlocks the trap idea.
5. **Kitchen**: ask babička for flour → the player gets `mouka`.
6. **Clothesline**: use the new sock and the flour → evening cutscene: the window, cocoa, Hanka falls asleep, the silhouette.
7. **Morning**: floury footprints and the red thread (`nitka`) → the path to the kitchen garden opens.
8. **Fence gap**: only **Hanka** fits through. She switches over and finds the thread on the raspberry bush.
9. **Stream**: click the stones in order (big, small, big). Alica helps Hanka across. Joey splashes.
10. **Shed**: dark. Hanka uses the torch → the boot with the thread → the dormice reveal cutscene.
11. **Ending**: talk to babička and děda → building the birdhouse (a mini-game: tap 3 nails) → the key found in the boot → "Pokračování příště…".

lupa, zapisnik, stara_ponozka, mouka, nova_ponozka, nitka, baterka, klic

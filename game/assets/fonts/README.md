# Fonts

`ShantellHand.ttf` and `ShantellHandBold.ttf` are Shantell Sans, unmodified and renamed on disk only.
© 2022 The Shantell Sans Project Authors, licensed under the SIL Open Font License 1.1: see
[OFL-shantellsans.txt](OFL-shantellsans.txt).

`TataHand.ttf` is the family's own font: Andrej's hand lettering, scanned from the style sheets and built by
`art/build_style.py` (every letter in two versions, alternated by the `calt` feature). The game's subtitles and
menus use it. Not for use outside this project.
